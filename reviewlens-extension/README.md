# ReviewLens Chrome Extension

Unpacked extension for extracting Shopify product reviews from the active page or a pasted product URL.

## Load in Chrome

1. Open `chrome://extensions`
2. Enable `Developer mode`
3. Click `Load unpacked`
4. Select this folder: `reviewlens-extension`

## Notes

- Popup supports a product URL input.
- The current MVP extracts visible review markup, JSON-LD, same-origin frames, and review-like network payloads captured in-page.
- The analysis panel is a placeholder for now.
