Download ReviewLens Extension

Use the extension directly on your Shopify product page. Free users can collect and view reviews; Pro users can unlock full AI analysis.

Download Extension Installation Guide
  1. 1
    Download the zip file
    Save the ReviewLens extension package to your computer.
  2. 2
    Unzip the package
    Open the extracted folder that contains manifest.json.
  3. 3
    Open chrome://extensions
    Enable Developer mode in the top-right corner.
  4. 4
    Load the extension
    Click Load unpacked and select the unzipped folder.
